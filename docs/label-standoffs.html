Reading the diagram

  • Dashed square — the icon's bounding box (side = ICON_SIZE). All standoffs are measured from this edge.
  • Amber line + dot — the standoff (icon edge → gap boundary at extent + gap). The label's closest visible edge lands on the dot: the baseline for top labels (so caps sit above), the cap top for bottom labels (so text sits below), and the vertical center for left / right. Descenders on top-labels (the p in top) intentionally hang a hair into the gap — that reads as a top-anchored label, not as clipping.
  • Both diagrams share one viewBox (3.6 × 3.6 world units), so the desktop marker visibly renders at half the mobile size — the constants scale in lockstep. Compare each diagram's 0.5-unit scale bar to see it at a glance.
  • Cap-height constant is EB Garamond's sCapHeight / unitsPerEm = 650 / 1000 = 0.65. Change the label font and this constant needs to change with it — the app's EB_GARAMOND_CAP_HEIGHT is where it lives.
